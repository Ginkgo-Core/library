# By Ginkgo Product

> Technology lookup by likely downstream owner/consumer.

## ai-stack

Use for shared runtime, provider routing, automation infrastructure, queues, voice/media service candidates and cross-stack security patterns.

## Sylvia

Use for agent orchestration, planning/review patterns, coding executors, context management and model/provider abstraction.

## Ginkgo Agents

Use for reusable skills, subagents, evals, prompts-as-policy, agent memory and experimental agent capabilities.

## Ginkgo Source

Use for reusable delivery patterns, reference implementations, design capabilities, solution composition and build-vs-buy intelligence.

## Ginkgo Connect

Use for governed read-only connectors, MCP context sources, provenance and normalized external data access.

## Pyre

Use for image/video/audio generation, creative providers, ComfyUI, avatars/identity, UGC and media pipelines.

## Wave

Use for ad-performance analysis, creative scoring, fatigue detection, spend/ROAS optimization and campaign feedback loops.

## Commerce OS

Use for product catalogs, affiliate commerce, offer generation, creative-commerce flows, distribution and revenue attribution.

## Leaf

Use only when a technology improves CRM/real-estate product capabilities directly. Avoid using Leaf as a generic platform laboratory.

## Scale Group

Use for creator operations, AI/synthetic identity workflows, social distribution, commerce operations and creator monetization systems.

## Rule

A technology may appear under several consumers, but it should have one **canonical owner** for the actual integration.

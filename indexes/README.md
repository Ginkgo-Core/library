# Library Indexes

Indexes are fast human/AI entrypoints generated from or synchronized with `registry/library.yaml`.

## Core indexes

- `ADOPT-NOW.md` — validated/high-priority items ready for a concrete target.
- `WATCHLIST.md` — useful items worth monitoring but not adopting yet.
- `OPEN-SOURCE.md` — open-source technologies.
- `SELF-HOSTABLE.md` — tools that can run under Ginkgo control.
- `LOW-COST.md` — low-cost/free candidates with operational caveats.
- `MCP.md` — MCP-capable projects and patterns.
- `BY-CAPABILITY.md` — lookup by functional capability.
- `BY-GINKGO-PRODUCT.md` — lookup by downstream product/repository.

## Rule

The registry is canonical. Indexes are views.

If an index and the registry disagree, fix the index unless the registry itself is demonstrably wrong.
